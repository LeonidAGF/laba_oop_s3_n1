# Лабораторная по ООП 1 Вариант 12


## Что было необходимо сделать.

Написать одну законченную консольную программу —
интерактивный справочник, который работает с C-строкой и выполняет над
ней набор операций, выбираемых из текстового меню. Вся логика оформляется
как библиотека чистых функций: функции не вводят и не выводят данные сами,
а принимают их параметрами, изменяют переданные структуры и возвращают результат. Работа состоит из двух
частей:

1. Часть 1 — единая программа варианта: C-строка, базовые операции семейства, алгоритм
варианта и поиск с возвратом результата и найденного значения по ссылке.
Вся логика — чистые функции,
собранные в один проект с текстовым меню.

2. Часть 2 — проект CMake с Google Test, который проверяет чистые функции
программы.

Запрещены классы, конструкторы, семантика копирования/перемещения,
std::string, std::vector, std::array и умные указатели. Работа с памятью — только
вручную (new[] / delete[]), строки — только C-строки 

Функции для реализации: 
	char* str_alloc(const char* src); // копия строки в новой динамической памят
	и
	std::size_t str_len(const char* s); // длина до '\0'
	void str_copy(char* dst, const char* src); // копирование в существующий буфер
	void str_delete(char*& s); // delete[] и обнулить
	void str_print(const char* s);
	void str_to_upper(char* s); — перевести латинские буквы в верхний регистр
	size_t str_count_char(const char* s, char ch) — сколько раз встречается символ.

Меню семейства:
1. Ввести строку 2. Напечатать
3. Длина 4. Скопировать в буфер и напечатать
5. Алгоритм варианта 0. Выход
